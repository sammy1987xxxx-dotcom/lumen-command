Dein LED-Streifen.
Dein Command Center.

Lumen Command macht aus einem ESP32 und einem WS2812B-Streifen eine WLAN-Leuchte mit schöner Weboberfläche, 54 Effekten, Musik-Effekten über Mikrofon und einem Türlicht, das dich beim Reinkommen begrüßt. Kostenlos, quelloffen, ohne Programmieren.

⚡ Jetzt installieren Code auf GitHub

English: Wi-Fi LED controller firmware for ESP32 + WS2812B with a clean web UI, 54 effects, music-reactive modes and a door light. Install it right here in your browser – the interface is in German.

Was kann Lumen Command?

Alles läuft direkt auf dem ESP32 – keine App, keine Cloud, kein Konto.

🖥️

Eigene Weboberfläche

Dunkles „Command Center“-Design, bedienbar mit Handy und PC im Browser.

✨

54 Effekte

Von ruhiger Nachtglut und Goldschweif bis Polarlicht, Feuer und Plasma – jeder Effekt einstellbar.

🎵

26 Musik-Effekte

Mit einem günstigen KY-037-Mikrofon reagiert der Streifen im Takt auf Musik.

🚪

Türlicht

Geht die Tür auf, wacht der Streifen von der Tür aus auf – als Nachtlicht oder goldene Welle.

🎨

LEDs einzeln malen

Jede LED einzeln färben und mit „LED-Nr. zeigen“ Positionen am Streifen finden.

Im Browser installieren

ESP32 per USB anstecken, auf „Installieren“ klicken, Port wählen – fertig. Keine Arduino IDE nötig.

Dein Browser unterstützt kein Web Serial. Bitte Chrome, Edge oder Opera am PC oder Mac verwenden (nicht auf dem Handy).

Die Installation braucht eine sichere Verbindung (https).

Bei der ersten Installation wird der ESP32 komplett gelöscht. Für Updates eines bereits eingerichteten Geräts besser die Update-Datei über die Weboberfläche hochladen – dann bleiben WLAN und Einstellungen erhalten: lumen-command-update.bin

  • Browser: Chrome, Edge oder Opera am Computer
  • Board: klassischer ESP32 (z. B. ESP32 DevKit / ESP32-WROOM-32, 4 MB Flash)
  • USB-Kabel mit Datenleitung – reine Ladekabel gehen nicht
  • Kein Port sichtbar? USB-Treiber für den Chip auf dem Board installieren (meist CP210x oder CH340)
  • Hängt beim Verbinden? BOOT-Taste am ESP32 gedrückt halten, bis es losgeht

Masse (GND) von ESP32, Netzteil und Streifen immer verbinden. Lange Streifen zusätzlich in der Mitte und am Ende mit 5 V einspeisen.

Einrichten in 2 Minuten

1

Hotspot

Mit dem WLAN LED-Controller-Setup verbinden, Passwort 1234567890.

2

Anmelden

http://192.168.4.1 öffnen, Benutzer admin, Passwort 1234567890.

3

WLAN eintragen

Unter „WLAN Konfiguration“ dein Heim-WLAN speichern – der ESP32 startet neu.

4

Loslegen

Neue Adresse im Router suchen, eigenes Passwort setzen, LED-Anzahl einstellen – fertig.

Türlicht

Lumen Command hört im Heimnetz auf UDP-Port 4210. Eine kurze Meldung genügt – von einem eigenen Türsensor, Home Assistant oder Node-RED. Die passende Türsteuerung wird später ebenfalls veröffentlicht.
